# Coddy Python Projects

Kleine Python-Übungsprojekte aus meinen Coddy-Kursen.

## Projekte

- **[expense-tracker](expense-tracker/)** — Konsolenprogramm zum Erfassen von Ausgaben mit Menü zum Hinzufügen, Anzeigen, Auswerten (Summe/Durchschnitt) und Löschen.
- **[pattern-finder](pattern-finder/)** — Findet alle (auch überlappende) Vorkommen eines Musters in einem Text und gibt Fundstatus, Anzahl und Positionen zurück.
